How the framework catches an attack

0 frames

  1. Every WiFi device nearby sends management frames, and the framework reads them as they arrive.
  2. The stream is cut into 1-second windows, and features are computed for each window.
  3. An attack starts, here a flood of deauthentication frames. The window model flags those windows.
  4. The detection feeds the device's 7-pillar trust score, and its trust falls.
  5. In his evaluation the flow model (Random Forest) reached 96.97% accuracy, and the window model (Voting Ensemble) 90.86% accuracy and 86.78% macro F1.1

A simulation of the pipeline. The frames, the attack and the trust score are illustrative.2

C-DAC Chennai · July 2025 – present

Zero Trust security for IoT networks.

As Project Engineer in AI Research & IoT Security, he built a real-time Zero Trust framework for IoT networks. Machine learning detects attacks, and what it finds feeds a continuous 7-pillar trust score for every device.

  • WiFi (802.11)
  • BLE
  • Zigbee
  • LoRa

Two models, two time scales

A window model sorts 1-second sliding windows of 802.11 management frames into 7 attack classes, and a flow model catches longer patterns. He compared RF, XGBoost, SVM, MLP and a Voting Ensemble over 6 preprocessing iterations, with SMOTE and Optuna (TPE) for the hyperparameter search, then used Youden's J threshold optimisation and protected feature selection to handle the 7-class imbalance.

63 features from raw captures

MAC entropy, frame-rate statistics, sequence gaps, EAPOL key MIC ratios and beacon timestamp variance, pulled from raw PCAPs with Scapy and PyShark. A memory-efficient streaming reader handles large files.

A live drop folder

A Watchdog pipeline picks up new PCAP files as they land, with stability checks, MD5 deduplication, multi-threaded frame extraction, batch inference and a lock for each shared resource.

Identity for every workload

SPIFFE/SPIRE workload identity, mTLS mutual authentication and OTP-based 2FA are built into the Zero Trust architecture.

Two papers on the framework · IoTaIS 2025, Bali

  • Protocol-Aware Continuous Monitoring and Anomaly Detection in IoT Networks
  • A Comprehensive Survey on Zero Trust Architecture in IoT Networks

Omniscience Pro · retrieval-augmented generation

A RAG system that stays on your machine.

Omniscience Pro is privacy-first and local. Built on LangChain and ChromaDB, it ingests documents of several kinds, retrieves the passages that answer a question, and hands them to a model running on the same hardware.

<50 ms vector search (HNSW) <500 ms to the first token

On consumer hardware, drawn to scale.4

Local and private

Documents and questions stay on the machine. Nothing goes to a hosted model.

Ships as a container

A GPU-aware Docker image with a full CI/CD pipeline.

Safe with many sessions

POSIX file locking keeps concurrent sessions from corrupting each other.

Python · LangChain · ChromaDB · Docker

ARO · Autonomous Research Operator

Multi-agent LLM workflows, run as a graph.

ARO runs each workflow as a directed graph in NetworkX. A Flask backend streams the agents' progress over Server-Sent Events to a React frontend, so you can watch the work as it happens.

Llama 3.2 for efficient inference

A fine-tuned model small enough for a consumer GPU.

He fine-tuned Llama 3.2 1B and 3B on 21.5k domain-specific interactions,6 for specialised task following and agentic use. Then 4-bit quantisation with Unsloth cut memory enough for a consumer GPU, with no meaningful drop in output quality against the full-precision models.
