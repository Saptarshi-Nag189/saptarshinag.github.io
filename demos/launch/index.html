How you find a pulsar

1 turn

  1. One turn of a pulsar is buried in the noise. You can't see it.
  2. Cut the recording at the pulsar's period and stack the turns. Each one on its own still looks like noise.
  3. Average the turns. The noise cancels and the pulse adds up. This is called epoch folding.
  4. At NCRA-TIFR he built a ResNet1D with Squeeze-and-Excitation attention that detects weak pulsars at 99.8% F1 across 70M+ samples.3

C-DAC Chennai · July 2025 – present

Zero Trust security for IoT networks.

As Project Engineer in AI Research & IoT Security, he built a real-time Zero Trust framework that covers WiFi (802.11), BLE, Zigbee and LoRa devices. Machine learning detects attacks, and what it finds feeds a continuous 7-pillar trust score for every device.

Two models, two time scales

A window model sorts 1-second windows of 802.11 management frames into 7 attack classes, and a flow model catches longer patterns. He compared RF, XGBoost, SVM, MLP and a Voting Ensemble over 6 preprocessing iterations, with SMOTE and Optuna (TPE).

63 features from raw captures

MAC entropy, frame-rate statistics, sequence gaps, EAPOL key MIC ratios and beacon timestamp variance, pulled from raw PCAPs with Scapy and PyShark. A streaming reader keeps memory flat on large files.

A live drop folder

A Watchdog pipeline picks up new PCAP files as they land, with stability checks, MD5 deduplication, multi-threaded frame extraction and batch inference.

Identity for every workload

SPIFFE/SPIRE workload identity, mTLS and OTP-based 2FA. He co-authored two papers on the framework at IoTaIS 2025 in Bali.

NCRA-TIFR, Research Intern

GMRT, HPC & Signal Processing

At the Giant Metrewave Radio Telescope he profiled the legacy CPU signal-filtering pipelines and refactored them for multicore execution. Latency fell by 50%, enough to process the telescope's continuous data stream in real time.

Four projects.

F1 tyre degradation and race strategy

It calls the pit stop from the telemetry.

A hybrid LSTM-XGBoost model predicts tyre wear and pit-stop windows from 10 Hz telemetry. A physics-informed loss separates thermal from mechanical degradation, and custom CUDA/CuPy kernels cut training time by 4.1×.5

Python · PyTorch · CUDA · CuPy · XGBoost

Omniscience Pro

A RAG system that stays on your machine.

Privacy-first and local, built on LangChain and ChromaDB, with multi-modal document ingestion. Search takes under 50 ms (HNSW) and the first token arrives in under 500 ms on consumer hardware.6 It ships as a GPU-aware Docker image with CI/CD, and POSIX file locking keeps concurrent sessions safe.

Python · LangChain · ChromaDB · Docker

ARO, Autonomous Research Operator

Research agents, run as a graph.

Multi-agent LLM workflows run as directed graphs in NetworkX, and a Flask backend streams progress to a React frontend over Server-Sent Events. After the build he audited it adversarially and fixed 16 vulnerabilities.7 SQLAlchemy-backed audit trails keep concurrent sessions safe.

Python · Flask · SQLAlchemy · NetworkX · React

Llama 3.2 for efficient inference

Small enough for a consumer GPU.

He fine-tuned Llama 3.2 1B and 3B on 21.5k domain-specific interactions,8 then quantised them to 4-bit with Unsloth. That cut memory enough for a consumer GPU, with no meaningful drop in output quality against the full-precision models.

Python · Unsloth · Hugging Face · PyTorch
