C-DAC (Centre for Development of Advanced Computing)

Project Engineer, AI Research & IoT Security

July 2025 – Present Chennai, India
  • Built a real-time Zero Trust security framework for IoT networks covering WiFi (802.11), BLE, Zigbee and LoRa. Its ML-based attack detection feeds a continuous 7-pillar device trust score.
  • Designed a two-stage detection pipeline. A window model sorts 1-second sliding windows of 802.11 management frames into 7 attack classes, and a flow model catches longer patterns. I compared RF, XGBoost, SVM, MLP and a Voting Ensemble over 6 preprocessing iterations, with SMOTE and Optuna (TPE) for the hyperparameter search.
  • Best results: 96.97% accuracy on flow classification (RF), and 90.86% accuracy / 86.78% macro F1 on window classification (Voting Ensemble). Youden's J threshold optimisation and protected feature selection handled the 7-class imbalance.
  • Engineered 63 statistical and behavioural features from raw PCAP captures with Scapy and PyShark: MAC entropy, frame-rate statistics, sequence gaps, EAPOL key MIC ratios and beacon timestamp variance. A streaming reader keeps memory flat on large files.
  • Wrote a live PCAP drop-folder pipeline on Watchdog observers, with stability checks, MD5 deduplication, multi-threaded frame extraction, batch inference and a lock per shared resource.
  • Integrated SPIFFE/SPIRE workload identity, mTLS and OTP-based 2FA, and co-authored the two IoTaIS 2025 papers on the framework.
